Beginner · Big idea

Meet the word-prediction machine

LLM means Large Language Model. “Large” refers to its huge number of learned parameters and training examples. “Language model” means it estimates what text is likely to come next.

🍕

Imagine the world’s most dedicated reader

Our character, Pixel, reads millions of books, articles, conversations, code examples, and recipes. But Pixel has one training game: cover the next piece of text and guess it.

After billions of guesses, Pixel learns grammar, style, facts, patterns, and even fragments of reasoning—not by storing a neat encyclopedia, but by adjusting billions of tiny numerical knobs.

Key mental model

An LLM is not a database that looks up a complete answer. It repeatedly predicts a probability distribution for the next token, chooses one, appends it, and repeats.

01
Beginner · Representation

Text becomes tokens

Models do not see words directly. A tokenizer breaks text into reusable chunks—whole words, pieces of words, spaces, and punctuation—and assigns each chunk an integer ID.

Lab · Tokenizer microscopeType anything

Watch a sentence become model food

🧩

Why pieces, not just words?

A vocabulary containing every possible word would be enormous. Pieces let the model handle names, typos, code, and new words such as “moonburger” → “moon” + “burger.”

🪟

Context windows count tokens

If a model supports 128,000 tokens, that is roughly 70,000–100,000 English words, depending on the text. Code and uncommon scripts tokenize differently.

Math bridge · From token to ID

tokenizer("cats") → ["cat", "s"] → [9246, 82]

The integers are just labels. The model next turns each ID into a vector of learned numbers.

02
Beginner → Intermediate · Vectors

Meaning becomes geometry

Each token ID maps to an embedding: a long list of numbers. During training, words used in similar ways develop vectors that point in similar directions.

Explore · Meaning mapClick a word

Which ideas live near each other?

Conceptual similarity

Real embeddings have hundreds or thousands of dimensions. This 2D map is an intuition, not a literal view.

Math basics · Vectors and cosine similarity

word → v = [0.21, −0.73, 0.42, …]
similarity(a,b) = (a · b) / (||a|| ||b||)

The dot product \(a · b\) is large when two vectors point in the same direction. Dividing by their lengths keeps the score between −1 and 1. Similar meaning often produces a score closer to 1.

Famous intuition, with a warning

Vector arithmetic sometimes captures relations like king − man + woman ≈ queen. It is a useful picture, but real model representations are contextual, distributed, and far messier than one clean equation.

03
Intermediate · Neural networks

Billions of tiny calculators

A neural network repeatedly mixes numbers using weights, adds biases, and applies nonlinear functions. One unit is simple; huge layers of them can represent astonishingly complicated patterns.

Math basics · One artificial neuron

z = w₁x₁ + w₂x₂ + b     then     output = activation(z)

Inputs \(x\) carry information. Weights \(w\) control importance. Bias \(b\) shifts the result. An activation function makes the system nonlinear; without it, many layers would collapse into one linear transformation.

Math bridge · Scaled dot-product attention

Attention(Q,K,V) = softmax(QKᵀ / √dₖ) V

Query Q: what am I looking for? Key K: what does each token offer? Value V: what information should be passed along? Dot products score matches; softmax turns scores into weights that sum to 1.

👥

Multi-head attention

Many attention heads run in parallel. One may track syntax, another names, another long-range dependencies.

📍

Position information

Because attention alone ignores order, models add positional information so “dog bites human” differs from “human bites dog.”

Intermediate · Learning

How an LLM learns

Training is an enormous loop: predict, measure error, calculate gradients, nudge parameters, repeat. The model slowly shifts probability toward the correct next token.

Math basics · Cross-entropy loss

loss = −log P(correct next token)

If the model gives the correct token probability 0.9, loss is small: \(-\log(0.9) ≈ 0.105\). If it gives probability 0.01, loss is large: \(-\log(0.01) ≈ 4.605\).

Math basics · Gradient descent

new weight = old weight − learning_rate × gradient

The gradient is the slope of the loss. Subtracting it moves downhill. The learning rate controls step size: too tiny is slow; too large may jump past the valley.

Intermediate · Inference

From probabilities to prose

The final layer produces a score, called a logit, for every token in the vocabulary. Softmax converts those scores into probabilities. A decoding strategy selects the next token.

Math bridge · Softmax with temperature

P(tokenᵢ) = exp(logitᵢ / T) / Σⱼ exp(logitⱼ / T)

Lower \(T\) sharpens the distribution, making high-probability choices dominate. Higher \(T\) flattens it, allowing more surprising choices. Temperature does not add knowledge; it changes sampling.

🥇

Greedy

Always choose the top token. Stable, but can become repetitive.

🎲

Sampling

Randomly choose according to probability. More varied outputs.

🧺

Top-p

Sample only from the smallest likely set whose probability totals \(p\).

Practical · Prompt engineering

Give the model a good map

A prompt supplies temporary context. Clear goals, relevant background, constraints, examples, and an output format reduce ambiguity and make success easier to verify.

Prompting is not magic wording

Think specification, not spell. Ask for evidence, define the audience, provide source material, split complex work into steps, and verify important outputs independently.

📌

Prompting

Put instructions and examples in the current context. Fast, no weight changes, but consumes context space.

🛠️

Fine-tuning

Continue training weights on curated examples to teach behavior, style, or a specialized task.

📚

RAG

Retrieve fresh external facts at answer time. Best when knowledge changes or citations matter.

🔌

Tool use

Let the model call calculators, databases, search, or software APIs instead of guessing.

Rule of thumb

Fine-tune for behavior; retrieve for knowledge; use tools for exact actions and calculations.

🧠

Scaling laws

Performance often improves predictably with more compute, data, and parameters—until data quality and other bottlenecks dominate.

🚦

Mixture of Experts

A router activates only a subset of specialist feed-forward networks per token, increasing capacity without using every parameter each time.

📦

Quantization

Store weights with fewer bits, reducing memory and often speeding inference with a controlled accuracy tradeoff.

Advanced math · Parameter count intuition

dense layer parameters ≈ input_dim × output_dim + bias

Transformer parameter counts grow mainly through large projection and feed-forward matrices repeated across many layers. “Parameters” measure capacity, not guaranteed intelligence or factuality.

09
Advanced · Responsible use

Powerful pattern learner, imperfect oracle

Fluent language can sound certain even when the underlying prediction is wrong. Understanding failure modes is part of understanding the technology.

🎭

Hallucination

The model generates plausible but unsupported claims because likelihood is not the same thing as truth.

🪞

Bias

Training data and feedback can encode social, cultural, and sampling biases.

🧮

Weak exactness

Language models may fail at long calculations, exact counting, or strict symbolic rules without tools.

🕰️

Knowledge limits

Weights reflect training data, not guaranteed current information. Retrieval can help, but sources still require judgment.

Use a verification ladder

For casual brainstorming, quick review may be enough. For code, run tests. For claims, inspect sources. For medical, legal, financial, security, or safety-critical decisions, involve qualified humans and authoritative evidence.

Pocket glossary

Token

A chunk of text represented by an integer ID.

Embedding

A learned vector representation that places useful properties into geometry.

Parameter

A numerical value learned during training, commonly a weight or bias.

Transformer

A neural architecture built around attention and feed-forward layers.

Attention

A method for mixing information between tokens according to learned relevance scores.

Logit

An unnormalized score produced before softmax converts scores to probabilities.

Inference

Running a trained model to produce predictions or text.

RAG

Retrieval-augmented generation: fetch relevant documents and add them to the prompt.

Gradient

A derivative showing how changing a parameter changes the loss.

Hallucination

A fluent output that is unsupported, fabricated, or incorrect.
