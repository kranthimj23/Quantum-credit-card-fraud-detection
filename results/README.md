# Results folder

Generated artifacts (metrics JSON, ROC/PR PNGs, raw score arrays) land here when
you run the pipeline. See `STEPS.md` in the repo root for the full execution
order.

This folder is intentionally empty in git so the repo stays small; everything
in here is regenerated by `python src/0X_*.py`.

Tracked file patterns (committed to the repo):
- `*.md` (this file)
- `.gitkeep`

Ignored file patterns (regenerated locally, see `.gitignore`):
- `*.npy` (raw score arrays)
- `*.pkl`, `*.joblib` (trained models)
- larger PNGs, intermediate logs

Smaller PNGs and JSON metric files **are** tracked so reviewers of the PR can
see baseline numbers without rerunning the pipeline. If you want to skip
committing those too, add them to `.gitignore`.
